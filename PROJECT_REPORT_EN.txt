                           1. PROJECT OVERVIEW

【What is this system?】

An automated trading system for Polymarket (a prediction/betting market platform)
that trades on live sports events using a momentum-following strategy.

【Current Status】

Running in "Paper Trading" mode - uses virtual money ($50,000) for testing.
No real money is involved.

【Core Components】

- Real-time price monitoring via WebSocket
- Automatic event filtering and scoring
- Momentum signal detection
- Automated position management
- Performance tracking and logging

================================================================================
                       3. PROFIT & LOSS CALCULATION
================================================================================

【From paper_trader.py lines 494-506, 537-588】

【Per-Trade P&L Calculation】

While position is OPEN (unrealized):
  unrealized_pnl = (current_price - entry_price) × quantity
  unrealized_pnl_pct = (current_price - entry_price) / entry_price

When position CLOSES (realized):
  realized_pnl = unrealized_pnl
  exit_amount = entry_amount + realized_pnl
  capital += exit_amount

【Concrete Example】

┌─────────────────────────────────────────────────────────────────────────────┐
│ EXAMPLE TRADE - PROFIT                                                      │
├─────────────────────────────────────────────────────────────────────────────┤
│ Initial Capital: $50,000                                                    │
│                                                                             │
│ Signal: MEDIUM (3.5% price rise detected)                                   │
│ Position Size: $150                                                         │
│                                                                             │
│ Entry:                                                                      │
│   • Price: $0.50                                                            │
│   • Quantity: $150 / $0.50 = 300 shares                                     │
│   • Capital after entry: $50,000 - $150 = $49,850                           │
│                                                                             │
│ Exit (Take Profit at +4%):                                                  │
│   • Price: $0.52 (4% above entry)                                           │
│   • P&L: ($0.52 - $0.50) × 300 = $6.00                                      │
│   • Exit amount: $150 + $6 = $156                                           │
│   • Capital after exit: $49,850 + $156 = $50,006                            │
│                                                                             │
│ Result: +$6.00 profit (+4%)                                                 │

│                                                                             │
│ Signal: WEAK (2.2% price rise detected)                                     │
│ Position Size: $100                                                         │
│                                                                             │
│ Entry:                                                                      │
│   • Price: $0.45                                                            │
│   • Quantity: $100 / $0.45 = 222.22 shares                                  │

                    8. ROOT CAUSE ANALYSIS & WARNINGS

【What is "Spread"?】

┌─────────────────────────────────────────────────────────────────────────────┐
│ SPREAD EXPLAINED                                                            │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                             │
│ Spread = The difference between the BUY price and SELL price                │
│                                                                             │
│ Example:                                                                    │
│   • Best Ask (buy price):  $0.52  ← Price to BUY                            │
│   • Best Bid (sell price): $0.48  ← Price to SELL                           │
│   • Spread: $0.52 - $0.48 = $0.04 (8% of mid-price)                         │
│                                                                             │
│ Impact on Trading:                                                          │
│   • If you buy at $0.52 and immediately sell, you get $0.48                 │
│   • Instant loss of 8% just from spread!                                    │
│   • With 4% take-profit target, spread alone can cause losses               │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘

【The REAL Problem: Buying at Price Spike Tops (Mean Reversion)】

┌─────────────────────────────────────────────────────────────────────────────┐
│ CRITICAL ISSUE IDENTIFIED FROM TRADING LOGS                                 │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                             │
│ The system is NOT suffering from latency issues.                            │
│ System latency is actually very fast: 0.02ms average (from summary log)     │
│                                                                             │
│ THE REAL PROBLEM:                                                           │
│                                                                             │
│ 1. System detects a 2%+ price RISE as a momentum signal                     │
│                                                                             │
│ 2. By definition, when signal triggers, price has ALREADY risen             │
│    (we're buying AFTER the rise, not before)                                │
│                                                                             │
│ 3. The "entry price" recorded is the price AFTER the spike                  │
│    Example: Entry at $0.99 (top of spike)                                   │
│                                                                             │
│ 4. Price immediately drops back down (MEAN REVERSION)                       │
│    Example: Exit at $0.01 within milliseconds                               │
│                                                                             │
│ 5. Result: Massive losses on most trades                                    │
│                                                                             │
│ MEAN REVERSION: Prices that spike up tend to fall back to their average.   │
│ By buying AFTER a spike, we're buying at the worst possible moment.         │
│                                                                             │
│ Examples from actual trades:                                                │
│   • Entry: $0.990 → Exit: $0.010 | P&L: -$98.99 | Hold: 0.00s               │
│   • Entry: $0.950 → Exit: $0.050 | P&L: -$94.74 | Hold: 0.01s               │
│   • Entry: $0.880 → Exit: $0.120 | P&L: -$86.36 | Hold: 0.00s               │
│                                                                             │
│ These extreme price drops (99% to 1%) in milliseconds suggest:              │
│   • Data anomalies or glitches in price feed                                │
│   • Market resolution events (game ending)                                  │
│   • Thin liquidity causing price jumps                                      │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘

【Strategy Limitations】

┌─────────────────────────────────────────────────────────────────────────────┐
