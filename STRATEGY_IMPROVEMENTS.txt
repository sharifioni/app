================================================================================
                    STRATEGY 1: FILTER EXTREME PRICE LEVELS
================================================================================

【Problem】

When a token price is very close to $0.00 or $1.00, it usually means:
- The market is about to resolve (game ending, outcome becoming certain)
- There's almost no liquidity (no one to trade with)
- Any trade will result in massive slippage

Example from logs:
  Entry: $0.99 → Exit: $0.01 (99% loss in milliseconds)

This happens because at $0.99, the outcome is nearly certain. When the game
ends, the price instantly goes to $1.00 (win) or $0.00 (lose). If you bought
at $0.99 expecting it to go higher, and the outcome was "NO", you lose 99%.

【Solution】

Add a price range filter that rejects signals when price is too extreme:

┌─────────────────────────────────────────────────────────────────────────────┐
│ IMPLEMENTATION                                                              │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                             │
│ # In paper_trader.py, add to signal detection (around line 400-433)        │
│                                                                             │
│ # Configuration                                                             │
│ MIN_SAFE_PRICE = 0.10  # Don't buy below $0.10                              │
│ MAX_SAFE_PRICE = 0.90  # Don't buy above $0.90                              │
│                                                                             │
│ def check_signal(self, token_id, current_price, ...):                       │
│     # FILTER 1: Reject extreme prices                                       │
│     if current_price < MIN_SAFE_PRICE:                                      │
│         self.logger.debug(f"Skipping {token_id}: price {current_price}"     │
│                           f" too low (< {MIN_SAFE_PRICE})")                 │
│         return None                                                         │
│                                                                             │
│     if current_price > MAX_SAFE_PRICE:                                      │
│         self.logger.debug(f"Skipping {token_id}: price {current_price}"     │
│                           f" too high (> {MAX_SAFE_PRICE})")                │
│         return None                                                         │
│                                                                             │
│     # Continue with existing signal logic...                                │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘

【Why This Works】

Price Range    | Risk Level | Reason
---------------|------------|------------------------------------------
$0.00 - $0.10  | VERY HIGH  | Outcome likely "NO", could go to $0.00
$0.10 - $0.90  | MODERATE   | Outcome uncertain, normal trading range
$0.90 - $1.00  | VERY HIGH  | Outcome likely "YES", could resolve to $1.00

By staying in the $0.10-$0.90 range:
- Avoid market resolution traps
- Ensure there's liquidity on both sides
- Maximum possible loss is ~90% instead of ~99%

【Expected Impact】

Based on log analysis, many of the worst losses came from extreme prices.
This filter alone could eliminate 30-50% of the largest losing trades.


================================================================================
                    STRATEGY 2: ADD CONFIRMATION PERIOD
================================================================================

【Problem】

Current system buys IMMEDIATELY when it detects a 2% price rise.
But many 2% moves are just noise - the price spikes up and immediately falls.

Current flow:
  1. Price rises 2% → Signal triggers → BUY immediately
  2. Price falls back → Stop loss hits → LOSS

This is like jumping on a moving train that's about to stop.

【Solution】

Wait for the price to HOLD above the threshold for a confirmation period
before entering. This filters out noise spikes.

┌─────────────────────────────────────────────────────────────────────────────┐
│ IMPLEMENTATION                                                              │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                             │
│ # Configuration                                                             │
│ CONFIRMATION_PERIOD = 3.0  # seconds                                        │
│ CONFIRMATION_THRESHOLD = 0.02  # 2% above baseline                          │
│                                                                             │
│ # Add to token tracking data structure                                      │
│ self.signal_candidates = {}  # token_id -> first_signal_time                │
│                                                                             │
│ def check_signal(self, token_id, current_price, baseline_price):            │
│     price_change_pct = (current_price - baseline_price) / baseline_price    │
│                                                                             │
│     if price_change_pct >= CONFIRMATION_THRESHOLD:                          │
│         # Price is above threshold                                          │
│         if token_id not in self.signal_candidates:                          │
│             # First time above threshold - start timer                      │
│             self.signal_candidates[token_id] = time.time()                  │
│             self.logger.info(f"Signal candidate: {token_id}, "              │
│                              f"waiting for confirmation...")                │
│             return None  # Don't buy yet                                    │
│         else:                                                               │
│             # Check if confirmation period has passed                       │
│             time_above = time.time() - self.signal_candidates[token_id]     │
│             if time_above >= CONFIRMATION_PERIOD:                           │
│                 # CONFIRMED! Price held above threshold                     │
│                 del self.signal_candidates[token_id]                        │
│                 return self.generate_signal(token_id, current_price, ...)   │
│             else:                                                           │
│                 return None  # Still waiting                                │
│     else:                                                                   │
│         # Price dropped below threshold - reset timer                       │
│         if token_id in self.signal_candidates:                              │
│             self.logger.debug(f"Signal cancelled: {token_id} "              │
│                               f"dropped below threshold")                   │
│             del self.signal_candidates[token_id]                            │
│         return None                                                         │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘

【Visual Explanation】

WITHOUT Confirmation (Current):

  Price
    ↑     ╭──╮
    │    ╱    ╲        ← BUY here (at peak)
    │   ╱      ╲
    │  ╱        ╲      ← SELL here (stop loss)
    │ ╱          ╲
    └─────────────────→ Time
         ↑
      Signal

WITH Confirmation (Proposed):

  Price
    ↑     ╭──╮
    │    ╱    ╲        ← NO BUY (didn't hold for 3 seconds)
    │   ╱      ╲
    │  ╱        ╲
    │ ╱          ╲
    └─────────────────→ Time
         ↑   ↑
      Signal │
             └── Would need to stay up for 3 seconds

【Expected Impact】

- Filters out 70-80% of noise spikes
- Only enters trades with sustained momentum
- Reduces trade frequency but improves win rate
- Trade-off: May miss some quick profitable moves


================================================================================
                    STRATEGY 3: CHECK SPREAD BEFORE ENTRY
================================================================================

【Problem】

Spread is the difference between buy price (ask) and sell price (bid).
If spread is 5% and your profit target is 4%, you're guaranteed to lose!

Example:
  Best Ask (buy):  $0.52
  Best Bid (sell): $0.48
  Spread: 8%

  You buy at $0.52
  Immediately sell at $0.48
  Loss: 8% (even if price didn't move!)

Wide spreads indicate:
- Low liquidity (few traders)
- High risk (hard to exit)
- Market makers taking large cut

【Solution】

Check the spread before entering any trade. Only enter if spread is
narrow enough to allow profitable exit.

┌─────────────────────────────────────────────────────────────────────────────┐
│ IMPLEMENTATION                                                              │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                             │
│ # Configuration                                                             │
│ MAX_SPREAD_PCT = 2.0  # Maximum acceptable spread (2%)                      │
│                                                                             │
│ def check_spread(self, token_id):                                           │
│     """                                                                     │
│     Get current order book and calculate spread.                            │
│     Returns spread percentage or None if unavailable.                       │
│     """                                                                     │
│     order_book = self.get_order_book(token_id)                              │
│     if not order_book:                                                      │
│         return None                                                         │
│                                                                             │
│     best_bid = order_book.get('best_bid')  # Highest buy order              │
│     best_ask = order_book.get('best_ask')  # Lowest sell order              │
│                                                                             │
│     if not best_bid or not best_ask:                                        │
│         return None                                                         │
│                                                                             │
│     mid_price = (best_bid + best_ask) / 2                                   │
│     spread = best_ask - best_bid                                            │
│     spread_pct = (spread / mid_price) * 100                                 │
│                                                                             │
│     return spread_pct                                                       │
│                                                                             │
│ def check_signal(self, token_id, current_price, ...):                       │
│     # ... existing checks ...                                               │
│                                                                             │
│     # FILTER: Check spread before entry                                     │
│     spread_pct = self.check_spread(token_id)                                │
│     if spread_pct is None:                                                  │
│         self.logger.warning(f"Cannot get spread for {token_id}, skipping")  │
│         return None                                                         │
│                                                                             │
│     if spread_pct > MAX_SPREAD_PCT:                                         │
│         self.logger.info(f"Spread too wide for {token_id}: "                │
│                          f"{spread_pct:.2f}% > {MAX_SPREAD_PCT}%")          │
│         return None                                                         │
│                                                                             │
│     # Spread is acceptable, continue with signal...                         │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘

【Spread Impact on Profitability】

Spread %  | Take Profit 4% | Net Profit | Viable?
----------|----------------|------------|--------
1%        | 4%             | +3%        | YES
2%        | 4%             | +2%        | YES
3%        | 4%             | +1%        | MARGINAL
4%        | 4%             | 0%         | NO
5%+       | 4%             | NEGATIVE   | NO

【Expected Impact】

- Ensures every trade has profit potential
- Avoids illiquid markets where exit is difficult
- May reduce trading opportunities but improves quality


================================================================================
                STRATEGY 4: CONTRARIAN / MEAN REVERSION TRADING
================================================================================

【Problem】

Current strategy: BUY when price RISES (momentum following)
Reality: Prices that spike up tend to fall back down (mean reversion)

This is why 80.9% of trades are losing - we're fighting mean reversion!

【Solution】

Instead of buying rises, consider buying DIPS and selling RISES.
This works WITH mean reversion instead of against it.

┌─────────────────────────────────────────────────────────────────────────────┐
│ MEAN REVERSION STRATEGY                                                     │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                             │
│ CURRENT (Momentum - Fighting Mean Reversion):                               │
│   Price rises 2%  → BUY  → Price falls back → LOSS                          │
│                                                                             │
│ PROPOSED (Contrarian - Using Mean Reversion):                               │
│   Price drops 2%  → BUY  → Price rises back → PROFIT                        │
│   Price rises 2%  → SELL → Price drops back → PROFIT                        │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────────────────────┐
│ IMPLEMENTATION                                                              │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                             │
│ # Configuration                                                             │
│ MEAN_REVERSION_THRESHOLD = -0.02  # Buy when price DROPS 2%                 │
│ TAKE_PROFIT_PCT = 0.02            # Exit when price recovers 2%             │
│ STOP_LOSS_PCT = -0.03             # Stop loss at 3% further drop            │
│                                                                             │
│ def check_signal(self, token_id, current_price, baseline_price):            │
│     price_change_pct = (current_price - baseline_price) / baseline_price    │
│                                                                             │
│     # CONTRARIAN: Buy when price DROPS                                      │
│     if price_change_pct <= MEAN_REVERSION_THRESHOLD:                        │
│         # Price has dropped - expect mean reversion UP                      │
│                                                                             │
│         # Additional safety checks                                          │
│         if current_price < 0.10 or current_price > 0.90:                    │
│             return None  # Avoid extreme prices                             │
│                                                                             │
│         signal_strength = self.calculate_strength(price_change_pct)         │
│         return {                                                            │
│             'type': 'BUY',                                                  │
│             'reason': 'MEAN_REVERSION',                                     │
│             'entry_price': current_price,                                   │
│             'target_price': current_price * (1 + TAKE_PROFIT_PCT),          │
│             'stop_price': current_price * (1 + STOP_LOSS_PCT),              │
│             'strength': signal_strength                                     │
│         }                                                                   │
│                                                                             │
│     return None                                                             │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘

【Visual Comparison】

MOMENTUM (Current - Losing):

  Price    ╭──╮
    ↑     ╱    ╲     BUY at peak
    │    ╱      ╲    ↓
    │   ╱        ╲   SELL at loss
    │  ╱          ╲  ↓
    └─────────────────→ Time

MEAN REVERSION (Proposed - Winning):

  Price    ╭──╮
    ↑     ╱    ╲     SELL at peak (or don't buy)
    │    ╱      ╲    ↓
    │   ╱        ╲   BUY at dip
    │  ╱          ╲  ↓
    └─────────────────→ Time

【When Mean Reversion Works Best】

Works well when:
- Price is in middle range ($0.30-$0.70)
- Market is liquid (tight spread)
- No major news/events causing permanent price shift
- Game is in progress (not about to end)

Does NOT work when:
- Price is near extremes (market resolving)
- Major event just happened (score change)
- Trend is strong and sustained

【Expected Impact】

- Could flip win rate from 19% to 60%+
- Works with market dynamics instead of against them
- Requires careful implementation to avoid catching "falling knives"


================================================================================
                    STRATEGY 5: MINIMUM HOLD REQUIREMENT
================================================================================

【Problem】

Current system exits immediately when stop-loss is hit.
With 87.5% of trades closing in under 1 second, we're reacting to noise.

Price fluctuations in the first few seconds are often just noise.
By exiting immediately, we're locking in losses that might have recovered.

【Solution】

Add a minimum hold period before allowing any exit (except extreme cases).
This gives trades time to develop and filters out noise.

┌─────────────────────────────────────────────────────────────────────────────┐
│ IMPLEMENTATION                                                              │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                             │
│ # Configuration                                                             │
│ MIN_HOLD_SECONDS = 5.0      # Minimum time before normal exit               │
│ EMERGENCY_STOP_PCT = -0.10  # Emergency exit at 10% loss (always active)    │
│                                                                             │
│ def check_exit_conditions(self, position):                                  │
│     current_time = time.time()                                              │
│     hold_duration = current_time - position['entry_time']                   │
│     unrealized_pnl_pct = position['unrealized_pnl_pct']                     │
│                                                                             │
│     # EMERGENCY EXIT: Always active (protects against catastrophic loss)   │
│     if unrealized_pnl_pct <= EMERGENCY_STOP_PCT:                            │
│         return {                                                            │
│             'should_exit': True,                                            │
│             'reason': 'EMERGENCY_STOP',                                     │
│             'message': f'Emergency exit at {unrealized_pnl_pct:.1%} loss'   │
│         }                                                                   │
│                                                                             │
│     # MINIMUM HOLD: Don't exit during initial period                        │
│     if hold_duration < MIN_HOLD_SECONDS:                                    │
│         return {                                                            │
│             'should_exit': False,                                           │
│             'reason': 'MIN_HOLD',                                           │
│             'message': f'Holding for {MIN_HOLD_SECONDS - hold_duration:.1f}s'│
│         }                                                                   │
│                                                                             │
│     # NORMAL EXIT CONDITIONS (after minimum hold)                           │
│     # Take profit                                                           │
│     if unrealized_pnl_pct >= TAKE_PROFIT_PCT:                               │
│         return {'should_exit': True, 'reason': 'TAKE_PROFIT'}               │
│                                                                             │
│     # Stop loss                                                             │
│     if unrealized_pnl_pct <= STOP_LOSS_PCT:                                 │
│         return {'should_exit': True, 'reason': 'STOP_LOSS'}                 │
│                                                                             │
│     # Timeout                                                               │
│     if hold_duration >= MAX_HOLD_SECONDS:                                   │
│         return {'should_exit': True, 'reason': 'TIMEOUT'}                   │
│                                                                             │
│     return {'should_exit': False, 'reason': 'HOLDING'}                      │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘

【Timeline Visualization】

0s          5s                                    300s
│───────────│─────────────────────────────────────│
│  MIN HOLD │        NORMAL TRADING               │ TIMEOUT
│  PERIOD   │                                     │
│           │                                     │
│ Only      │ Normal stop-loss (-2%)              │ Force
│ emergency │ Normal take-profit (+4%)            │ exit
│ stop      │ Reversal detection                  │
│ (-10%)    │                                     │
│ active    │                                     │

【Expected Impact】

- Prevents panic exits on temporary dips
- Gives trades time to develop
- May increase average loss per losing trade
- But should significantly increase win rate
- Net effect: Better overall P&L


================================================================================
                STRATEGY 6: VOLUME-WEIGHTED SIGNAL CONFIRMATION
================================================================================

【Problem】

Current system checks if volume increased 30%, but doesn't verify:
- How long the volume increase lasted
- Whether volume is sustained or just a spike
- The absolute volume level (not just percentage change)

A brief volume spike followed by silence is often noise, not real momentum.

【Solution】

Require sustained volume over a period, not just a momentary spike.

┌─────────────────────────────────────────────────────────────────────────────┐
│ IMPLEMENTATION                                                              │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                             │
│ # Configuration                                                             │
│ MIN_VOLUME_DURATION = 3.0    # Volume must stay elevated for 3 seconds      │
│ MIN_ABSOLUTE_VOLUME = 100    # Minimum dollar volume in period              │
│ VOLUME_INCREASE_PCT = 0.30   # 30% increase threshold                       │
│                                                                             │
│ # Track volume history per token                                            │
│ self.volume_history = {}  # token_id -> list of (timestamp, volume)         │
│                                                                             │
│ def update_volume(self, token_id, volume):                                  │
│     """Track volume updates with timestamps."""                             │
│     current_time = time.time()                                              │
│                                                                             │
│     if token_id not in self.volume_history:                                 │
│         self.volume_history[token_id] = []                                  │
│                                                                             │
│     self.volume_history[token_id].append((current_time, volume))            │
│                                                                             │
│     # Keep only last 60 seconds of data                                     │
│     cutoff = current_time - 60                                              │
│     self.volume_history[token_id] = [                                       │
│         (t, v) for t, v in self.volume_history[token_id] if t > cutoff      │
│     ]                                                                       │
│                                                                             │
│ def check_sustained_volume(self, token_id):                                 │
│     """                                                                     │
│     Check if volume has been elevated for the required duration.            │
│     Returns True if volume criteria met, False otherwise.                   │
│     """                                                                     │
│     if token_id not in self.volume_history:                                 │
│         return False                                                        │
│                                                                             │
│     history = self.volume_history[token_id]                                 │
│     if len(history) < 2:                                                    │
│         return False                                                        │
│                                                                             │
│     current_time = time.time()                                              │
│                                                                             │
│     # Calculate baseline volume (10-60 seconds ago)                         │
│     baseline_data = [(t, v) for t, v in history                             │
│                      if current_time - 60 <= t <= current_time - 10]        │
│     if not baseline_data:                                                   │
│         return False                                                        │
│     baseline_volume = sum(v for t, v in baseline_data) / len(baseline_data) │
│                                                                             │
│     # Calculate recent volume (last MIN_VOLUME_DURATION seconds)            │
│     recent_data = [(t, v) for t, v in history                               │
│                    if t > current_time - MIN_VOLUME_DURATION]               │
│     if not recent_data:                                                     │
│         return False                                                        │
│     recent_volume = sum(v for t, v in recent_data) / len(recent_data)       │
│                                                                             │
│     # Check criteria                                                        │
│     volume_increase = (recent_volume - baseline_volume) / baseline_volume   │
│     if baseline_volume > 0 else 0                                           │
│                                                                             │
│     if volume_increase >= VOLUME_INCREASE_PCT:                              │
│         if recent_volume >= MIN_ABSOLUTE_VOLUME:                            │
│             return True                                                     │
│                                                                             │
│     return False                                                            │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘

【Volume Pattern Analysis】

NOISE (Don't Trade):

  Volume
    ↑      │
    │      │     ← Single spike
    │      │
    │ ─────┴─────────── ← Returns to baseline
    └─────────────────────→ Time

REAL MOMENTUM (Trade):

  Volume
    ↑      ┌─────────────
    │      │             ← Sustained elevation
    │      │
    │ ─────┘             ← Clear increase from baseline
    └─────────────────────→ Time

【Expected Impact】

- Filters out volume spikes that don't indicate real interest
- Ensures there's actual trading activity to support the move
- Reduces false signals from thin/manipulated markets
