                           1. 项目概述
================================================================================

【这是什么系统？】

这是一个自动化交易系统，用于在 Polymarket（预测市场/博彩平台）上
对实时体育赛事进行动量跟随策略交易。

【当前状态】

系统运行在"模拟交易"模式，使用虚拟资金（$50,000）进行测试。
不涉及真实金钱。

【核心组件】

- 通过 WebSocket 实时监控价格
- 自动筛选和评分赛事
- 动量信号检测
- 自动化仓位管理
- 绩效追踪和日志记录

【策略：动量跟随】

系统检测价格快速上涨，并顺势交易。

================================================================================
                         3. 盈亏计算方式
================================================================================

【来自 paper_trader.py 第494-506行，537-588行】

【单笔交易盈亏计算】

持仓期间（未实现盈亏）：
  未实现盈亏 = (当前价格 - 入场价格) × 数量
  未实现盈亏百分比 = (当前价格 - 入场价格) / 入场价格

平仓时（已实现盈亏）：
  已实现盈亏 = 未实现盈亏
  退出金额 = 入场金额 + 已实现盈亏
  资金 += 退出金额

【具体示例】

┌─────────────────────────────────────────────────────────────────────────────┐
│ 示例交易 - 盈利                                                             │
├─────────────────────────────────────────────────────────────────────────────┤
│ 初始资金：$50,000                                                           │
│                                                                             │
│ 信号：中等（检测到3.5%价格上涨）                                            │
│ 仓位大小：$150                                                              │
│                                                                             │
│ 入场：                                                                      │
│   • 价格：$0.50                                                             │
│   • 数量：$150 / $0.50 = 300 份                                             │
│   • 入场后资金：$50,000 - $150 = $49,850                                    │
│                                                                             │
│ 出场（止盈 +4%）：                                                          │
│   • 价格：$0.52（比入场价高4%）                                             │
│   • 盈亏：($0.52 - $0.50) × 300 = $6.00                                     │
│   • 退出金额：$150 + $6 = $156                                              │
│   • 出场后资金：$49,850 + $156 = $50,006                                    │
│                                                                             │
│ 结果：+$6.00 盈利（+4%）                                                    │
└─────────────────────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────────────────────┐
│ 示例交易 - 亏损                                                             │
├─────────────────────────────────────────────────────────────────────────────┤
│ 初始资金：$50,006                                                           │
│                                                                             │
│ 信号：弱信号（检测到2.2%价格上涨）                                          │
│ 仓位大小：$100                                                              │
│                                                                             │
│ 入场：                                                                      │
│   • 价格：$0.45                                                             │
│   • 数量：$100 / $0.45 = 222.22 份                                          │
│   • 入场后资金：$50,006 - $100 = $49,906                                    │
│                                                                             │
│ 出场（止损 -2%）：                                                          │
│   • 价格：$0.441（比入场价低2%）                                            │
│   • 盈亏：($0.441 - $0.45) × 222.22 = -$2.00                                │
│   • 退出金额：$100 - $2 = $98                                               │
│   • 出场后资金：$49,906 + $98 = $50,004                                     │
│                                                                             │
│ 结果：-$2.00 亏损（-2%）                                                    │
└─────────────────────────────────────────────────────────────────────────────┘

【测试订单成本计算】

┌─────────────────────────────────────────────────────────────────────────────┐
│ 测试订单成本                                                                │
├─────────────────────────────────────────────────────────────────────────────┤
│ 放置测试订单时：                                                            │
│   • 资金 -= $5（立即扣除）                                                  │
│   • 测试订单成本 += $5（统计中记录）                                        │
│                                                                             │
│ 测试订单过期时（无信号）：                                                  │
│   • 资金 += $5 × 0.98 = $4.90（返还98%）                                    │
│   • 每个过期测试订单净成本：$0.10（2%损失）                                 │
│                                                                             │
│ 测试订单触发信号时：                                                        │
│   • 测试订单被移除                                                          │
│   • 开立仓位（单独的资金扣除）                                              │
│   • 原始 $5 不返还（纳入仓位逻辑）                                          │
└─────────────────────────────────────────────────────────────────────────────┘

【统计指标（paper_trader.py:148-179, 590-626）】

┌──────────────────┬──────────────────────────────────────────────────────────┐
│ 指标             │ 计算方式                                                 │
├──────────────────┼──────────────────────────────────────────────────────────┤
│ 胜率             │ 盈利交易次数 / 总交易次数                                │
│ 盈利因子         │ 总盈利金额 / 总亏损金额                                  │
│ 平均盈利         │ 总盈利金额 / 盈利交易次数                                │
│ 平均亏损         │ 总亏损金额 / 亏损交易次数                                │
│ 最大回撤         │ (峰值资金 - 当前资金) / 峰值资金                         │
│ 测试订单成本     │ 所有测试订单的累计 $5 扣除                               │

                         5. 系统运行方式
================================================================================

【安装】

cd c:\Users\shahj\Downloads\Project
pip install -r requirements.txt

【运行模拟交易仪表板】

streamlit run momentum_trader\dashboard\paper_trading_dashboard.py

【运行实时监控仪表板】

streamlit run momentum_trader\dashboard\realtime_dashboard.py

【语言切换】

两个仪表板都支持中英文：
• 在侧边栏找到"语言"下拉菜单
• 选择"中文"切换到中文界面

【数据输出】

所有交易数据保存到：trading_logs/
• prices_*.csv - 所有价格更新
• trades_*.csv - 已完成交易
• signals_*.csv - 检测到的信号
• latency_*.csv - 系统延迟指标

                        6. 重要风险警告
================================================================================

【策略局限性】

┌─────────────────────────────────────────────────────────────────────────────┐
│ 问题 1：延迟劣势                                                            │
├─────────────────────────────────────────────────────────────────────────────┤
│ • 专业交易者反应时间 < 1 秒                                                 │
│ • 本系统延迟 2-5 秒                                                         │
│ • 当检测到信号时，价格可能已经变动                                          │
└─────────────────────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────────────────────┐
│ 问题 2：价差成本                                                            │
├─────────────────────────────────────────────────────────────────────────────┤
│ • 典型价差：1-5%                                                            │
│ • 目标利润：4%                                                              │
│ • 价差可能吃掉全部利润空间                                                  │
└─────────────────────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────────────────────┐
│ 问题 3：假信号                                                              │
├─────────────────────────────────────────────────────────────────────────────┤
│ • 大多数 2% 的价格波动只是噪音，不是真正的动量                              │
│ • 预期胜率可能低于 50%                                                      │
│ • 止损(-2%) vs 止盈(+4%) 的比例有帮助但不能保证盈利                         │
└─────────────────────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────────────────────┐
│ 问题 4：测试订单成本                                                        │
├─────────────────────────────────────────────────────────────────────────────┤
│ • 每个测试订单预先花费 $5                                                   │
│ • 过期订单只返还 $4.90（2% 损失）                                           │
│ • 需要很多测试订单才能找到信号                                              │
│ • 累计测试成本可能很可观                                                    │
└─────────────────────────────────────────────────────────────────────────────┘


================================================================================
                    7. 真实交易注意事项
================================================================================

【真实交易的要求】

1. Polymarket 账户
   • 注册并完成身份验证
   • 充值 USDC（稳定币）

2. API 凭证
   • 获取用于订单签名的私钥
   • 在 clob_api.py 中配置

3. 需要的代码修改
   • 在 clob_api.py 中启用真实订单执行
   • 添加钱包签名功能
   • 为真实订单实现适当的错误处理

【建议】

1. 运行模拟交易较长时间（建议 72+ 小时）
2. 在考虑真实资金前仔细分析结果
3. 如果继续，从最小资金开始（$100-500）
4. 设置严格的每日亏损限制
5. 在初始真实交易期间持续监控系统
